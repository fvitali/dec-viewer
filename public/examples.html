Here you can find a few examples of RDF sets exploring DEC modal reasoning for subjective states of minds and representation of disgreements, uncertainties and lies.

All these examples are available using named graphs, rdf star triples and reification triples.

In the DEC model, permeation determines which statements are accessible (or: permeate) from one cognitive world to another. These permeations affect also what kind of reasoning is possible in each cognitive world. This generates several types of cognitive worlds: verbatim, shared, doxastic, epistemic, conjectural, reality. See the introduction for more information.

Here you will find a few examples using classes with arbitrary names and exactly ONE individual (entityX) to explore in the simplest way the different types of permeation and reasoning affored by DEC worlds.

There are several DEC graphs each exploring a different type of DEC reasoning. Graph g1 is shared knowledge and provides content for all graphs (except verbatim). Graph g2 is verbatim, and does not interact with the other graphs and performs no inferences. Graph g3 is doxastic, does not interact with the other graphs but uses the shared knowledge and performs local inferences. Graph g4 is epistemic, and generates true facts. It uses the shared knowledge, and all its inferences permeate into the default graph. Graph g5 is conjectural, and adds additional statements to true facts. It uses the shared knowledge and the default graph, but does not permeate to anywhere. The default graph permeate from the shared knowledge and epistemic graph g4, and permeates into conjectural graph g5.

GRAPH ex:g1 { ex:entityX rdf:type ex:A . ex:entityY rdf:type ex:Z. } ex:g1 rdf:type dec:sharedWorld . ex:A rdfs:subClassOf ex:B . GRAPH ex:g2 { ex:A rdfs:subClassOf ex:C . } ex:g2 rdf:type dec:verbatimWorld . GRAPH ex:g3 { ex:A rdfs:subClassOf ex:D . } ex:g3 rdf:type dec:doxasticWorld . GRAPH ex:g4 { ex:A rdfs:subClassOf ex:E . } ex:g4 rdf:type dec:epistemicWorld . GRAPH ex:g5 { ex:A rdfs:subClassOf ex:F . } ex:g5 rdf:type dec:conjecturalWorld .

Graph g1 (shared) does not change. Graph g2 (verbatim) does not change. Graph g3 (doxastic) permeates from the shared knowledge g1, and therefore asserts that entityX is of type A (from shared) and of type D (from itself), but not of type B (from default graph). The default graph permeates from the shared knowledge g1, and from the epistemic graph g4, therefore asserts that entityX is of type A (from shared), of type B (from itself), and of type E (from g4). Graph g5 (conjectural) permeates from the shared knowledge g1 and from the default graph, and therefore asserts that entityX is of type A (from shared), of type B (from the default graph), and of type E (from itself). The default graph permeates from the shared knowledge g1, and from the epistemic graph g4, but not from the conjectural graph g5, therefore asserts that entityX is of type A (from shared), of type B (from itself) and of type E (from epistemic graph g4).

Graph g1 is shared knowledge. Graph g2 is verbatim, so no inferences are made. The default graph uses the shared knowledge, graph g2 does not.

Catherine is correct in her knowledge. Moby Dick is indeed a mammal.

Moby Dick is a whale. This is a fact known to everybody. Catherine is aware that whales are mammals. Since it is specified inside an epistemic world, this also ends up being a fact. Therefore, Moby Dick is a whale, a mammal and an animal.

Superman's paradox is a well known paradox in logic. Lois Lane, Superman's fiancee, knows that Superman can fly. Since Superman and Clark Kent are the same person, does she know that Clark Kent can fly? We show the same example in three syntaxes: rdf-star, reification and named graphs.

This is the usual representation of the paradox of Superman using rdf-star triples. By default rdf-star triples are considered verbatim worlds, and thereore no inference on them are drawn.

:superman owl:sameAs :clarkkent. :loislane :thinks << :superman :can :fly >>.

One may be tempted to deduce that Lois Lane thinks that Clark Kent can fly. Yet, there is no inference happening on the owl:sameAs and therefore and no paradox here.

This is a doxastic version of Superman's problem. Assigning a doxastic nature seems the best choice in this case, because it introduces a subjective world completely separate from reality and independent from it. Whatever happens in reality has no impact on Lois Lane inner thoughts.

:superman owl:sameAs :clarkkent. :loislane :thinks << :superman :can :fly >>. :thinks a dec:doxasticPredicate.

Predicate :thinks is specified as a doxastic predicate, so it does not allow permeation to and from reality even if inferences are allowed. Therefore, no paradox takes place.

The only way to generate a Superman's paradox with DEC is to assume that Lois Lane's thoughts actually are conjectures, i.e., they permeate facts from reality). This choice would indeed generate the feared paradox.

:superman owl:sameAs :clarkkent. :loislane :thinks << :superman :can :fly >>. :thinks a dec:conjecturalPredicate.

The only way to force the paradox is to specify predicate :think as a conjectural predicate, which therefore permeates to reality. Under this assumption, we are required to conclude that Lois Lane thinks that Clark Kent can fly.

This is an exactly equivalent dataset that uses subclasses instead of sameAs relationships, and yet generate an equivalent paradox. It is not a referential problem, but an inferential one!

:SuperHero rdfs:subClassOf :FictionalBeing. :loislane :thinks << :superman a :SuperHero >>

One may be tempted to deduce that Lois Lane thinks that Superman is a fictional being. This also is a paradox, but it is not a referential one: even if there are no references involved, the statement are still paradoxical.

Again, if we choose a doxastic relationship, the paradox does not appear.

:thinks a dec:doxasticPredicate. :SuperHero rdfs:subClassOf :FictionalBeing. :loislane :thinks << :superman a :SuperHero >>

Again, the only way to generate the paradox is using a conjecture.

:thinks a dec:conjecturalPredicate. :SuperHero rdfs:subClassOf :FictionalBeing. :loislane :thinks << :superman a :SuperHero >>

In this case, in fact, Lois Lane thinks that Superman is a fictional being. The paradox appears here because we decided that Lois Lane's opinion was a conjecture, and therefore reality permated inside the local world.

This is the usual representation of the paradox of Superman using a named graph.

:superman owl:sameAs :clarkkent. :loislane :thinks :S1 GRAPH :S1 { :superman :can :fly. }

One may be tempted to deduce that Lois Lane thinks that Clark Kent can fly. Yet, by default we treat rdf-star statements as verbatim, there is no inference and no paradox here.

Shakespeare authorship question is the argument that someone other than William Shakespeare of Stratford-upon-Avon wrote the works attributed to him. Delia Bacon's The Philosophy of the Plays of Shakespeare Unfolded (1857) proposed the first "group theory". It attributed the works of Shakespeare to "a little clique of disappointed and defeated politicians" led by Sir Walter Raleigh which included Sir Francis Bacon and perhaps Edmund Spenser, Lord Buckhurst, and Edward de Vere. Gilbert Slater's The Seven Shakespeares (1931) proposed that the works were written by seven different authors: Francis Bacon, Edward de Vere, Sir Walter Raleigh, William Stanley, Christopher Marlowe, Mary Sidney, and Roger Manners In the early 1960s, Edward de Vere, Francis Bacon, Roger Manners, William Herbert and Mary Sidney were suggested as members of a group referred to as "The Oxford Syndicate". Christopher Marlowe, Robert Greene and Thomas Nashe have also been proposed as participants. Francis Bacon was proposed as sole author by William Henry Smith in 1856. A case for Edward De Vere, 17th Earl of Oxford's, authorship was discusssed by J. Thomas Looney (1920). Christopher Marlowe was first proposed as the sole author of Shakespeare's "stronger plays" in 1895 by Wilbur G. Zeigler. William Stanley, 6th Earl of Derby, was first proposed as a candidate in 1891 by James Greenstreet. Although the idea has attracted much public interest, all but a few Shakespeare scholars and literary historians consider it a fringe theory, and for the most part acknowledge it only to rebut or disparage the claims.

Flavius Eutropius, a historian who lived in Rome and Constantinople between 363 and 387 AD, wrote about the building of a wall in the northern part of Britain, under the orders of Septimius Severus, the Roman emperor who reigned between 193 and 211 AD. The venerable Bede, the English monk and historian who lived between 672 and 735 AD, tried to make sense of Eutropius' claim of a wall built by Severus, and since he knew the one much further north had been built by Antoninus Pius (142 AD), he inferred that the wall by Severus mentioned by Eutropius was the one much further south. In 1840 priest and historian John Hodgson, while writing his magnus opus "History of Northumberland," challenged the long-standing attribution of the wall to Severus. Since the book he was writing only tangentially regarded the wall, he devoted a single footnote in volume III to his doubts. But since he was a thorough scholar, this footnote is a remarkable 173 pages long and provides ground-breaking evidence supporting the attribution of the wall to Hadrian rather than Severus. Hodgson's ideas became accepted and adopted as the correct attribution of the wall, up to this day.

The so-called Donation of Constantinei> is a supposed 4th-century decree by Emperor Constantine transferring authority over Rome and the western Roman Empire to the Pope. In the DEC model, a disagreement is a pair of worlds that cannot be or become true at the same time: an inconsistency is generated when considering them both at the same time. A delusional world is a world that disagrees with reality. There are two ways to verify the existence of a disagreement:

  • Through a reasoning engine and dec:checkInconsistencies;
  • Through the dec:closedFor predicate.

We all agree (shared world g1) that entity is of type A, and that classes B and C are disjoint. But while world g2 believes that A is a subclass of B, world g3 knows as a fact that A is a subclass of C.

GRAPH ex:g1 { ex:entity rdf:type ex:A . ex:B owl:disjointWith ex:C. } GRAPH ex:g2 { ex:A rdfs:subClassOf ex:B . } GRAPH ex:g3 { ex:A rdfs:subClassOf ex:C . } [] dec:checkInconsistencies true. ex:g1 rdf:type dec:sharedWorld . ex:g2 rdf:type dec:doxasticWorld . ex:g3 rdf:type dec:epistemicWorld .

When we carry out the OWL-based inconsistency check, we discover that g2 and g3 can never be true at the same time, because that would render entity of both class B and C, which is forbidden. So they disagree. In addition, g3 is an epistemic world, which means that all the statements it contains permeate to reality, i.e., they are facts. This implies that g2 disagrees with reality and therefore is a delusional world.

A whale is a mammal, and no mammal is also a fish. These are facts. Yet, Bruce is convinced that whales are fishes. And we all know that Moby Dick is a whale.

Moby Dick is a whale and therefore a mammal. Bruce is convinced that Moby Dick is a whale and therefore a fish. Bruce therefore is delusional, since his beliefs disagree with reality.

The dec:closedFor approach does not require the specification of inconsistency rules. It assumes that every competing world provides a complete and not modifiable set of statements for specific subjects and predicates. Thus rdf:subject dec:closedFor rdfs:subClassOf implies that every world is closed for the use of rdfs:subClassOf on the same subjects.

GRAPH :fallacy { zoo:Whale rdfs:subClassOf zoo:Fish. } :bruce :believes :fallacy. :aristotle :found :discovery. GRAPH :discovery { zoo:Whale rdfs:subClassOf zoo:Mammal. } GRAPH :shared { :mobydick a zoo:Whale. } :shared a dec:sharedWorld . :believes a dec:doxasticPredicate . :found a dec:epistemicPredicate. rdf:subject dec:closedFor rdfs:subClassOf

Since both Aristotle's discovery and Bruce's fallacious beliefs use rdfs:subClassOf on whales, they violate the closed for clause on rdfs:subClassOf, and therefore they are disagreeing. In addition, Aristotle's discovery is epistemic, and therefore true, which makes Bruce's belief delusional.
